# Image Generation Prompt Optimization

Este repositorio contiene prompts optimizados para generación de imágenes con IA.

## Archivos / Files

### 1. `optimized_prompt.md`
Documento completo con el prompt optimizado en español e inglés, incluyendo:
- Descripción detallada del sujeto
- Requisitos clave para mantener consistencia
- Parámetros técnicos para generadores de imágenes IA

Complete document with optimized prompt in Spanish and English, including:
- Detailed subject description
- Key requirements to maintain consistency
- Technical parameters for AI image generators

### 2. `prompt_simple.txt`
Versión simplificada y concisa del prompt, lista para copiar y pegar en generadores de imágenes IA como:
- Stable Diffusion
- Midjourney
- DALL-E
- Leonardo.ai
- Y otros

Simplified and concise version of the prompt, ready to copy and paste into AI image generators like:
- Stable Diffusion
- Midjourney

- And others

## Uso / Usage

### Para generar una imagen consistente / To generate a consistent image:

1. Usa el prompt en `prompt_simple.txt` / Use the prompt in `prompt_simple.txt`
2. Asegúrate de usar la misma semilla (seed) que la imagen de referencia / Make sure to use the same seed as the reference image
3. Mantén los mismos parámetros técnicos / Keep the same technical parameters
4. Ajusta según necesites / Adjust as needed

## Características Clave / Key Features

✅ Mismo persona / Same person
✅ Misma ropa / Same clothes  
✅ Misma posición / Same position
✅ Expresión feliz y natural / Happy and natural expression
✅ Sosteniendo bocina / Holding speaker
✅ Alta calidad fotográfica / High photographic quality

## Consejos / Tips

- Si la primera generación no es perfecta, ajusta la semilla (seed) ligeramente
- Puedes ajustar el CFG Scale entre 7-9 para mejor balance
- Para mayor consistencia, usa el mismo modelo y versión del generador IA
- Experimenta con diferentes samplers (DPM++ 2M Karras, Euler A) para mejores resultados

- If the first generation isn't perfect, adjust the seed slightly
- You can adjust CFG Scale between 7-9 for better balance
- For greater consistency, use the same AI generator model and version
- Experiment with different samplers (DPM++ 2M Karras, Euler A) for better results
